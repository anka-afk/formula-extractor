# 公式提取器

粘贴 AI 回答，全文渲染其中的行内与行间 LaTeX 公式，点击公式即可复制到 Obsidian / Typora 等笔记软件。

在线使用：<https://anka-afk.github.io/formula-extractor/>

## 功能

- **全文渲染**：保留原文段落、标题、列表、表格与代码块，公式就地渲染为 KaTeX。
- **表格渲染与复制**：Markdown 表格渲染为可横向滚动的表格，支持对齐、单元格内公式与转义竖线；点击表格任意位置或右上角“复制表格”按钮即可复制整张表格的 Markdown。即使内容里没有公式，全文和表格也会照常渲染并可复制。
- **点击即复制**：点击任意公式即可按当前格式复制，支持 `$...$` / `$$...$$`、`\(...\)` / `\[...\]`、纯公式和原始包装。
- **富文本恢复**：从剪贴板 HTML 的 MathML / KaTeX 注解中还原 LaTeX 源码，即使纯文本里没有公式源码也能提取。
- **卡片视图**：逐条预览、编辑、筛选、搜索，支持批量复制与导出 Markdown。
- **纯前端**：没有后端、没有外部请求，所有内容只在浏览器本地处理；构建产物是单个 HTML 文件，可离线使用。
- **本地保存**：输入、公式、编辑结果、复制格式与主题保存在浏览器本地。

## 使用

1. 打开页面，把 AI 回答整段粘贴进输入框。
2. 公式会自动提取，右侧默认显示全文渲染结果。
3. 点击公式直接复制；点击表格可复制整张表格；也可以切到“卡片”视图编辑或批量复制。
4. 在右上角下拉框选择目标笔记软件的公式格式，默认是 Markdown（`$` / `$$`）。

## 本地构建

需要 Node.js 18+：

```bash
node build.mjs
node tests/parser.test.cjs
```

构建会生成两个内容相同的文件：

- `formula-extractor.html`：离线单文件版本，双击即可使用。
- `index.html`：GitHub Pages 入口。

KaTeX 的 JS、CSS 与字体都会内联进 HTML，因此构建产物不依赖网络。

## 目录

```
src/            页面结构、样式、解析器与交互逻辑
tests/          解析器单元测试
vendor/katex/   KaTeX 0.19.1 发行文件（MIT）
build.mjs       单文件构建脚本
```

## 已知限制

- 如果剪贴板里既没有 LaTeX 源码，也没有 MathML / KaTeX 注解（例如公式是图片），网页无法还原公式源码。
- 富文本内容使用会话缓存，刷新页面仍可保留；关闭标签页后重新打开时会回退为纯文本渲染。
